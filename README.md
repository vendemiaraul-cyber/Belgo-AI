# Belgo AI

A chat companion who lives on the chat bar. His brain runs in the browser with WebLLM (or through an API key), and he has his own v86 computer that boots a disc image.

## Built-in disc

Add a disc image to the repository root named `disc.iso` (or `disc.img`). It appears as "Start built-in disc" in Belgo's computer panel.

## Video maker

The film button opens a video panel that sends your description to [Agnes Video Generator](https://github.com/lcy362/agnes-video-generator) by lcy362, running on your own computer. The panel lists the steps to connect it.
