Belgo's brain

No key, no account, no download. Belgo first uses his own AI, which runs gpt-oss on this site's Cloudflare account, and the header shows "Own AI" when it answers. If that is not available he falls back to the free Pollinations text service, where your messages are then sent.

To get a token: on GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens, and generate one with the account permission Models set to Read-only. It is free, with a daily limit (about 150 answers on the small models). The token goes only from this page to GitHub. Your messages are sent to GitHub Models.

Runs on your device's processor with wllama, so it works in any modern browser. Bigger models answer better but are slower and need more memory. Each one downloads once. If a model fails to load, Belgo tries the next smaller one by himself.
