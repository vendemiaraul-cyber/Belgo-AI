# Belgo AI

A chat companion who lives on the chat bar. His brain is a free online model by default, or runs on the device with WebLLM, or uses an API key or a local server such as LM Studio. He can paint pictures, and he has his own v86 computer that boots a disc image.

## Built-in disc

Add a disc image to the repository root named `disc.iso` (or `disc.img`). It appears as "Start built-in disc" in Belgo's computer panel.
