# Belgo AI

A chat companion who lives on the chat bar. His brain runs in the browser with WebLLM (or through an API key), and he has his own v86 computer that boots a disc image.

## Built-in disc

Add a disc image to the repository root named `disc.iso` (or `disc.img`). It appears as "Start built-in disc" in Belgo's computer panel.

## Video maker

The film button opens a video panel with two styles, both without a key or sign-up:

- **Unlimited**: [Pollinations](https://pollinations.ai) paints pictures of the scene and Belgo animates and records them in the browser. No daily limit; the motion is camera moves over still pictures.
- **Real motion**: the public [LTX-Video Space](https://huggingface.co/spaces/Lightricks/ltx-video-distilled) by Lightricks makes a true video clip. Free use is capped each day.
